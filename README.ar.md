# جودوهكو — مكتب الزواج الإندونيسي الحديث

**اللغات:** [Indonesia](README.md) · [English](README.en.md) · [العربية](README.ar.md)

منصة مواعدة مميزة + دردشة آمنة + تعارف مُوجَّه + مجتمع، مبنية على Laravel 13. اكتشاف بأسلوب تيندر، وتوفيق بأسلوب سكاديت، ومكتب زواج إندونيسي، ومساعد ذكاء اصطناعي، وعلامة بيضاء متعددة العلامات — منتج واحد متكامل.

## المميزات

### الاكتشاف والتوفيق
- **الاكتشاف والتوفيق**: تقييم توافق من 8 أبعاد (`MatchingEngine`)، وفلاتر صارمة للحظر/الحالة، واختيارات يومية؛ التعزيز يؤثر على الترتيب فقط.
- **إعجاب / إعجاب مميز / مفضلة / تراجع**: الإعجاب المتبادل يُنشئ `matches` معياريًا بلا تكرار (`LikeService`). الخطة المجانية محدودة يوميًا (`FREE_DAILY_LIKES`، الافتراضي 20)، والمميزة بلا حدود؛ "من أعجب بك" والزوار للمميزة فقط.
- **الفلاتر المحفوظة**: حفظ وإعادة تسمية وتكرار وتعيين افتراضي وحذف (بحد أقصى 10) — ويب + API ‏`/api/v1/saved-filters`‏، جاهز لفلاتر.
- **وضع الجواز/السفر**: موقع افتراضي للمميزة مع سجل تدقيق؛ لا تُكشف الإحداثيات الدقيقة أبدًا (تُقرَّب المسافات إلى 0.5 كم).
- **شرح التوافق**: النقاط + أسباب "لماذا تتوافقان" (`MatchExplanation`، ومكوّن `why-match`، وواجهة الشرح).

### الملف الشخصي والصور والفيديو
- **ملفات مصقولة**: معرض صور، صورة غلاف، أسئلة وأجوبة، استبيان، نقاط الاكتمال، حالة الاتصال، شارات التحقق والتميز والتعزيز.
- **صور آمنة**: خط `PhotoService` (نوع MIME الحقيقي + الأبعاد، تصغير 1600 + مصغرات 400، كشف التكرار SHA-256، معلَّق → مراجعة الإدارة)؛ الصور المعلَّقة/الخاصة لا تظهر للعامة أبدًا.
- **فيديو الملف**: MP4/MOV حتى 50MB، بحد أقصى 3/مستخدم، رفض الملفات المموَّهة، بانتظار مراجعة الإدارة، وحدّ مدة اختياري عبر `FFPROBE_PATH`.
- **تحقق متدرج**: شارات البريد/الهاتف/الصورة/الهوية (من الطلبات المعتمدة)، ورفع الوثائق إلى تخزين خاص، ومراجعة الإدارة، وسجل تدقيق.

### السلامة
- **مركز السلامة**: الإبلاغ عن المستخدم/الرسالة/الملف/الصورة، والحظر، وإلغاء التوافق، وكتم الصوت، والتقييد، وسجل البلاغات — من الملف والتوافق والدردشة والمكالمات.
- **حظر جهات الاتصال**: يحافظ على الخصوصية (بصمات HMAC، لا تُخزَّن الأرقام الخام)، ومدمج في الاكتشاف.
- **إشراف محلي أولًا**: `ProfanityService` + `ScamDetectionService` ← `MessageModerationService` (سماح/حجب/تحذير/تصعيد/منع)؛ مراجعة الذكاء الاصطناعي عند التصعيد فقط؛ طابور إدارة + معالجة جماعية + استئناف.
- **الاحتيال**: نقاط مخاطر (IP/السرعة/الجهاز)، وأنماط الاحتيال العاطفي، وعتبات مراجعة بشرية — لا حظر تلقائي بإشارات ضعيفة.

### الدردشة والمكالمات والتنبيهات
- **دردشة فورية**: محادثات مباشرة، وعدم تكرار `client_message_id`، وإيصالات القراءة، والتفاعلات، والردود، والمرفقات (تنزيل عبر API بسياسة)، وبث الكتابة عبر Reverb، ومسودات لكل محادثة (تخزين محلي)، وشريط عدم الاتصال.
- **مكالمات صوت/فيديو**: دورة حياة + فوترة idempotent بالدقيقة (`CallService`)، وWebRTC ‏(`call.js`: ‏STUN/TURN‏ وICE وكتم/كاميرا وإعادة اتصال ومؤقت)، وسجل مكالمات؛ الفائتة/المرفوضة لا تُفوتر أبدًا.
- **التنبيهات**: إعجاب، وإعجاب مميز، وتوافق، ورسائل، وإشارات، وهدايا، ومدفوعات، وتحقق، وتعارف، ومكالمات — قاعدة بيانات + فوري + بريد + دفع؛ تفضيلات دقيقة؛ روابط عميقة.
- **الدفع**: تجريد المزوّد (الافتراضي `log` القابل للتدقيق؛ FCM HTTP v1 OAuth2 + احتياطي قديم)، ورموز متعددة الأجهزة، وتعطيل الرموز التالفة تلقائيًا.

### تحقيق الدخل والنمو
- **المميزة**: مجاني/مميز/VIP ‏(`MembershipService`/`SubscriptionService`)‏، وتُفرَض الاستحقاقات في الخادم، وليس الواجهة فقط.
- **التعزيز**: شراء بـ50 رصيدًا، وعدّاد، وتأثير ترتيب، وسجل، وانتهاء مجدول، ومنع إساءة (إنفاق بمرجع idempotent).
- **الهدايا**: كتالوج، وإرسال/استلام، وسجل، وتنبيهات، وحماية من الاحتيال.
- **الإحالة والتسويق بالعمولة**: رموز/روابط، وتتبع، ومكافآت idempotent، ولوحة + مشاركة، وعمولات + موافقة الإدارة.
- **المدفوعات**: 4 بوابات إندونيسية (iPaymu/Xendit/Midtrans/Tripay)، وwebhooks HMAC idempotent ‏(`event_id`)‏، واسترداد يبدأ من البوابة + استرداد بدون سالب.

### الذكاء الاصطناعي والتعارف والمستشارون
- **صانع التوافق الذكي**: يوصي فقط بمستخدمين حقيقيين من `DiscoveryService` (مؤسَّس، لا يخترع)، واستخراج الفلاتر باللغة الطبيعية + شروحات.
- **مساعد الذكاء**: نبذة، وأسئلة، وكاسرات جليد، واقتراحات ردود، وأفكار مواعيد — لا يرسل تلقائيًا أبدًا؛ حدود معدل + سقف ميزانية + سجلات استخدام.
- **دورة التعارف**: توافق ← طلب ← قبول ← قيم/دين/أسرة ← مستشار ← إتمام، مع أولياء/مرافقين، وقواعد مراحل، وتذكيرات، وتدقيق.
- **سوق المستشارين**: ملفات، وتقييمات، وحجز آمن من التعارض، ومدفوعات، وجلسات فيديو/دردشة، وأرباح، وعمولات إدارية.
- **أعضاء افتراضيون شفافون**: حسابات `virtual`/`ai` موسومة دائمًا، وأنماط قالب/هجين/ذكاء، ومحفزات + حدود يومية + ساعات نشاط، واستلام المشغّل يوقف الذكاء.

### المجتمع والفعاليات
- **الرسم الاجتماعي**: متابعة/إلغاء/كتم + مقترحون (`FollowService`)، وخصوصية دقيقة.
- **الخلاصة**: `FeedService` (مرشحون ← فلترة ← تقييم ← ترتيب ← ترقيم)، والرائج، وتعزيز المنشورات 24 ساعة بالرصيد، وحفظ/مشاركة/6 تفاعلات/هاشتاغ/إشارات.
- **قصص 24 ساعة**، و**مجموعات** (أدوار + أغلفة + دعوة/طلب + صفحات عامة `/g/{slug}`)، و**منتديات/مدونة**، و**بحث شامل** واعٍ بالخصوصية.
- **الفعاليات**: لقاءات online/offline‏، وRSVP ← اكتشاف الحاضرين (`/events/{event}/kenalan` + API مقترحة)، وبحث جوار جغرافي.

### الإدارة والتحليلات والأمان
- **مركز تحكم الإدارة**: لوحة KPI، وقمع كامل (تسجيل ← تحقق ← اكتشاف ← إعجاب ← توافق ← دردشة ← مكالمة ← تعارف ← دفع)، وتحليل الأفواج، وتدقيق بلا أسرار، وأسرار بوابات مشفرة.
- **مركز الخصوصية**: الظهور، والتخفي، والحظر/الكتم، وحظر جهات الاتصال، وتصدير البيانات، والإيقاف، وحذف دائم بأسلوب GDPR (إخفاء الهوية + إلغاء الرموز/الجلسات)، وإدارة الجلسات.
- **الأمان**: 2FA بريد-OTP + مصادق TOTP ‏(RFC 6238‏ وQR ورموز احتياطية أحادية)، وOTP هاتف HMAC + حدود معدل، وتقييد تسجيل الدخول/التسجيل، وسياسات مسجلة كاملة، ومنع IDOR، ورفع مُتحقق.
- **SEO/PSEO**: خريطة موقع ديناميكية، وrobots‏، و14 مدينة + 5 مواضيع ببوابات جودة، وJSON-LD‏، وملفات عامة اختيارية.

### الجوال وPWA والواجهة
- **صفحة هبوط مميزة**: بطل، وكيف يعمل، ومتصلون الآن، وأعضاء تجريبيون، ومعاينة خلاصة، وعضوية، وأسئلة، ودعوة — جوال أولًا.
- **PWA**: بيان واعٍ بالعلامة، وعامل خدمة + بديل عدم الاتصال، وأيقونات، وتثبيت.
- **API جاهز لفلاتر**: ‏`/api/v1/`‏ متسق (مصادقة واكتشاف ودردشة ومكالمات وملف واجتماعي وفعاليات ومدفوعات ودفع وفلاتر) + مسودة OpenAPI ‏(`docs/API-V1-OPENAPI.yaml`)‏.
- **عرض تجاري**: `php artisan jodohku:demo --users=5000` (حتمي، وبالجملة، وصور اصطناعية آمنة) — انظر `DEMO.md`.

### العلامة البيضاء Tier 3 (متعدد العلامات)
- جدول `brands`: الاسم والشعار والألوان والشعار والنطاق وأعلام الميزات — حل حسب النطاق (تخزين ساعة)، وبديل Jodohku.
- معالج تأهيل 4 خطوات (معاينة حية + معاينة هبوط)، وإدارة CRUD‏، وتصدير/استيراد zip.
- تخطيطات/بريد/بيان/PWA واعية بالعلامة + أيقونات تثبيت؛ وتُفرَض الأعلام في الخادم (`brand.feature` ← 404).
- دور `client`: يدير علامته فقط (`BrandPolicy`)؛ و`users.brand_id` ينسب التسجيل. انظر `WHITELABEL.md`.

## التقنية

Laravel 13 · ‏PHP 8.3‏ · ‏Sanctum‏ · ‏Reverb‏ · طوابير database/redis‏ · ‏SQLite‏ (تطوير/اختبار) / ‏MySQL‏ (إنتاج) · تخزين S3‏ · ‏Vite‏ + ‏Tailwind‏ · ‏Livewire‏ · ‏Alpine.js‏ (مضمّن).

## البدء السريع

```bash
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install && npm run dev
php artisan serve
php artisan reverb:start
php artisan queue:work
```

الاختبار والبذر الجديد:

```bash
php artisan migrate:fresh --seed --force
php artisan test   # 280 passed
```
